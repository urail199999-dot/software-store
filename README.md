# Магазин программ
Основа магазина на Laravel 13 и Filament 5. Русская панель управления: /admin.

## Возможности
- Товары: название, описание, цена в рублях с копейками, ссылка, публикация.
- Ключи: отдельный запас для каждого товара, проверка дубликатов, шифрование в базе.
- Заказ: email покупателя, снимок цены и названия, секретный адрес страницы заказа.
- После подтверждения оплаты администратором покупателю доступны один ключ и ссылка.
- Повторное подтверждение не расходует новый ключ. При отсутствии ключей заказ остаётся неоплаченным.
- Только администраторы имеют доступ в Filament. Вход по логину, ограничение попыток.

## Локальный запуск
Требуются PHP 8.3+ с curl, fileinfo, intl, mbstring, openssl, pdo_sqlite, sqlite3, zip и Composer.

```powershell
composer install
Copy-Item .env.example .env
php artisan key:generate
New-Item database/database.sqlite -ItemType File -Force
php artisan migrate
php artisan storage:link
php artisan filament:assets
php artisan store:create-admin your-login
php artisan serve --host=127.0.0.1 --port=8000
```

Пароль вводится скрыто. В текущем локальном экземпляре администратор уже создан по данным владельца; пароль отсутствует в исходниках. На Windows можно запустить start-store.ps1. Он находит PHP в PATH или в подготовленном локальном окружении.

Для загрузки изображений настройте в php.ini `upload_max_filesize=6M` и `post_max_size=64M`, затем перезапустите PHP. Ограничение формы остаётся 5 МБ на картинку. На Windows локальный запуск сохраняет TEMP/TMP для временных загрузок; start-store.ps1 дополнительно использует --no-reload.

Откройте http://127.0.0.1:8000 и http://127.0.0.1:8000/admin.

## Как проверить магазин
В разделе админки «Разделы и подразделы» создавайте дерево каталога: выберите родителя для подраздела, загрузите обложку, задайте порядок и включите публикацию. Скрытие родительского раздела скрывает всю ветку и её товары. Удаление доступно только для пустых разделов.

В «Товарах» можно выбрать раздел, загрузить главную картинку и до 8 дополнительных изображений. Поддерживаются JPG, PNG и WebP до 5 МБ на файл. Дополнительные изображения показываются в галерее на отдельной странице товара. Каталог доступен по адресу /catalog; поиск, фильтр наличия и сортировка работают на витрине. Загруженные файлы сохраняются в storage/app/public и не попадают в Git. Резервные копии сервера должны включать эту папку вместе с базой данных.

1. В админке создайте товар. Вводите цену в рублях: 199 или 199,90 (199 рублей 90 копеек). Укажите действительную ссылку на программу.
2. Добавьте ключ активации для товара и опубликуйте товар.
3. На витрине оформите заказ, сохраните секретный адрес заказа.
4. Получив оплату, откройте «Заказы» и нажмите «Подтвердить оплату».
5. Обновите страницу заказа: появятся ключ и кнопка скачивания.

## Кабинет покупателя и email
Регистрация /register и вход /login используют email, пароль и Google reCAPTCHA v2 («Я не робот»). После регистрации отправляется письмо с подписанной ссылкой на 60 минут. Неподтверждённые пользователи не получают доступ к кабинету и не могут оформлять заказы под аккаунтом. Кабинет /account показывает только заказы текущего пользователя, оформленные после входа; ключ и загрузка доступны после оплаты. Гостевые заказы сохраняют доступ по секретной ссылке и не присваиваются автоматически по совпадению email. Есть восстановление пароля по одноразовой ссылке; клиентские формы не сбрасывают пароль администратора.

Для отправки через Gmail включите двухэтапную аутентификацию и создайте пароль приложения Google (https://myaccount.google.com/apppasswords). В .env задайте:

```dotenv
MAIL_MAILER=smtp
MAIL_SCHEME=smtp
MAIL_HOST=smtp.gmail.com
MAIL_PORT=587
MAIL_USERNAME=your-address@gmail.com
MAIL_PASSWORD=your-app-password
MAIL_FROM_ADDRESS=your-address@gmail.com
MAIL_FROM_NAME=NEXORA
RECAPTCHA_SITE_KEY=your-v2-checkbox-site-key
RECAPTCHA_SECRET_KEY=your-secret-key
RECAPTCHA_HOSTNAMES=127.0.0.1,localhost
```

Ключи создаются в https://www.google.com/recaptcha/admin/create для типа v2 Checkbox. Добавьте домены сайта, а для локальной проверки — localhost и 127.0.0.1. На сервере RECAPTCHA_HOSTNAMES должен содержать только фактические домены сайта, APP_URL — его HTTPS-адрес. Секреты указываются только в .env, без коммита в Git. После изменения выполните php artisan config:clear. Для SMTP на 587 используется автоматический STARTTLS; в PHP должен быть настроен актуальный доверенный CA bundle (curl.cainfo и openssl.cafile), без отключения проверки сертификатов.

При отсутствии ключей reCAPTCHA проверка не пропускает запросы. Регистрация недоступна с MAIL_MAILER=log или array: эти режимы не доставляют письма. Пока SMTP и ключи не заполнены, реальная отправка и проверка CAPTCHA не активны. В тестах доставка и ответы Google подменены; фактическую доставку нужно проверить после заполнения .env.

## Ограничения первой версии
Платёжный провайдер ещё не подключён. Нет автоматического списания денег: подтверждение выполняет администратор после фактического получения оплаты. Письма о подтверждении email и восстановлении пароля подключены через SMTP; отправка писем о заказах пока не добавлена. Внешняя ссылка на программу становится известна покупателю при скачивании; для ограничения дальнейшего распространения потребуется приватное файловое хранилище и временные ссылки.

Каталог изначально пуст: реальные программы и лицензионные ключи добавляет владелец. Дизайн базовый, предназначен для дальнейшего согласования.

## Размещение на сервере
Нужен PHP-хостинг или VPS; статический хостинг Sites не исполняет Laravel/PHP. Направьте web root в public, настройте HTTPS, APP_URL, APP_ENV=production, APP_DEBUG=false, SESSION_SECURE_COOKIE=true, постоянную БД и резервное копирование. Сохраните APP_KEY: без него невозможно расшифровать ключи и ссылки. Не публикуйте .env, database.sqlite, рабочие логи или ключи программ. Перед началом продаж настройте платёжный провайдер с проверкой подписи webhook, суммы, валюты и повторных событий.
